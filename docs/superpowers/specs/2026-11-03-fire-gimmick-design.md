# 燃えるギミック 設計書

日付: 2026-11-03（改訂: 同日、体にまとう＋リアル寄りに変更）
対象: natsuki_ver02 プロジェクトのアバター（シーンで使っているのは reko.prefab。VRChat SDK 3.10.3 / PC 想定）

## 目的

Expression メニューのトグルで、炎が体全体にまとわりつくギミックを追加する。
アバター本体のマテリアルとメッシュは変更しない。

## 前提・仮定

- Modular Avatar / VRCFury は使わず、標準の SDK（Expression Menu / Parameters / FX Animator）で組む。
- Quest/Android 対応は不要。
- 炎の素材はエディタースクリプトでゼロから生成する（Unity 標準 Particle System と、スクリプトで描いたスプライト PNG）。
- 見た目はリアル寄り。詳細は「炎の見た目」を参照。

## 構成

既存アセットに追加する（対象アバターのディスクリプタが参照しているもの）:

- Expression Menu: 「燃える」トグルを追加
- Expression Parameters: `Fire`（Bool、同期あり）を追加
- FX コントローラー: `Fire` レイヤーを追加。`Fire` が true の間、炎オブジェクトを有効化するクリップを再生

新規:

- 炎オブジェクト（初期非アクティブ、アバター直下）
  - `Fire_<メッシュ名>`: 対象メッシュごとに1つ。Shape を Skinned Mesh Renderer にして、メッシュの表面全体から炎を出す
  - 対象メッシュは、アバター内の Skinned Mesh Renderer のうち、名前に `Face` / `Hair` を含まないもの（reko では Body と Cloth）
  - `Fire_Embers`: 火の粉。最初の対象メッシュの表面から出す
- 対象アバターは、選択中のプレハブ（またはシーン上のインスタンス）。決まらなければシーン内の唯一のアバター。どちらでも決まらなければエラーで止める
- 生成物はアバターごとに `Assets/natsuki_veer02/Fire/<プレハブ名>/` に出力する
- 生成スクリプトは `Assets/natsuki_veer02/Editor/Fire/`（1ファイル600行以内、役割ごとに分割）

## 炎の見た目

リアル寄りの炎にする。

- スプライト: ノイズで揺らいだ、輪郭のやわらかい炎の形（グレースケール、4×4 の16コマ）。火の粉用に、やわらかい丸のスプライトも作る
- 描画: Additive（加算合成）で光って見せる
- 色: 時間とともに、白っぽい黄 → オレンジ → 赤 → 暗い赤と変わり、最後は透明に消える
- 動き: World 空間で上に立ち上る。Noise モジュールでゆらぐ。動くと後ろにたなびく
- 火の粉: 小さく明るい粒が、ゆっくり舞い上がって消える
- 煙は入れない（負荷のため）
- 色・量・サイズは、スクリプト冒頭の定数にまとめる。数値を変えて再生成できる

## パフォーマンス

- Particle System は対象メッシュ数＋1（reko では3つ）
- 最大パーティクル数は、炎の合計 280 以下、火の粉 60 以下。全体で 350 以下
- 当たり判定、ライト、サブエミッターは使わない
- 非アクティブ時は負荷ゼロ

## エラー処理

- スクリプトは冪等にする。再実行時は既存の `Fire_*` オブジェクトとレイヤーを作り直し、重複させない
- 対象メッシュが1つもない場合は、何も書き込まずにエラーで止める
- パラメータの空き（256bit 上限）が足りない場合、またはメニューが満杯の場合は、何も書き込まず中断してエラーを出す
- 既存アセット（プレハブ、FX、パラメータ、メニュー）を書き換える前にバックアップを取る

## テスト

自動で確認する:

- `Fire` パラメータが登録されている
- メニューに「燃える」がある
- FX レイヤーに `Fire` レイヤーがある
- 炎オブジェクトが、対象メッシュごとに1つと火の粉1つある。Face / Hair からは出さない
- 炎はメッシュ表面から出る（Shape が Skinned Mesh Renderer）
- パーティクル数の上限を守っている

見た目の確認は、炎オブジェクトを一時的に有効にして Scene ビューで見るか、VRChat の Build & Test で、人が目視する。

## 範囲外

- 服や髪が焦げる、燃え落ちるシェーダー表現
- 煙
- ジェスチャー発動、Contact による発動
- Quest 対応
