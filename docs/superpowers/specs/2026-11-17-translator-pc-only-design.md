# 翻訳を PC だけで — 設計

## なぜ
スマホのローカル AI（Gemma 1B / 4B）は訳の質が足りなかった（利用者が 4B も試して「よくない」）。
翻訳を DeepL（ネットのサービス、速い）にするなら、スマホの AI は要らない。PC のマイクはもう使っているので、
**translator_pc.exe が全部やる**: PC のマイク → 音声認識 → DeepL → ペットの上の字幕（KAT）/ チャットボックス。
スマホは要らない（スマホ版は消さずに残す）。

## 決まったこと（利用者）
- 翻訳は DeepL（速さ優先で選択）
- PC だけで全部（スマホ不要）
- 自分は日本語と英語しか話さない
- 文の区切りは 1.2 秒の無音
- 重さ: 音声認識は話し終わりに 0.1〜0.3 秒だけ。画面に 1 文ごとの時間と CPU を出して確かめる

## 作り（translator_pc.exe を育てる）
- 音声認識: sherpa-onnx 2.0.1（.NET）の SenseVoice int8（スマホと同じモデル）。自動判定が日本語でも
  「2 語以上の英文」でもなければ、日本語に固定した認識器で聞き直す（スマホの JaEnRecognizer と同じ）
- 区切り: スマホの Segmenter を移植（PC マイクの設定: floorMin 60、無音 1.2 秒）
- 翻訳: DeepL API（無料キーは末尾 `:fx` → api-free.deepl.com、それ以外 api.deepl.com）。
  日本語 → 英語（EN-US）または中国語（ZH-HANS）。英語 → 日本語。キーは
  `%APPDATA%\VRCTranslatorPC\settings.json` に保存し、画面にもログにも出さない
- 表示: スマホの KatOsc / Compose / KatDisplay を移植（位置を先に、文字は 0.1 秒後）。
  日本語は KAT のためにかなへ（LibNMeCab + IPA 辞書）。中国語の訳はチャットボックスへ
- 「翻訳」オン・オフ: VRChat から来る TranslatorActive（9001）。オンの間だけマイクを開く
- 画面: 状態（マイク・翻訳オン/オフ・DeepL のキーあり/なし・相手言語）、最新の自分の文と訳、
  1 文ごとの時間（認識 / DeepL）と CPU。キー操作: K = DeepL のキーを入れる、L = 相手言語 英語/中国語、Ctrl+C = 終了
- 記録: 1 文ごとに TSV（時刻・言語・原文・訳・エンジン）。音声もキーも残さない

## しないこと
- スマホとの中継・音声送信は使わない（コードは残す）。相手の声の翻訳は次の段階
- Gemini は入れない（必要になったら同じ「翻訳」インターフェースに足す）

## 残す判断（私の判断）
- 画面はコンソールのまま（今の exe と同じ。ウィンドウ化は後で）
- DeepL が失敗したら字幕に「…」を消して記録に理由を書く（スマホ版と同じ）
