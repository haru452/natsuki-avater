# 翻訳ペット（アバター側・第1段階）設計書

日付: 2026-11-16
対象: natsuki_ver02 プロジェクト（VRChat SDK 3.10.3 / PC・デスクトップモード想定）
もとの資料: 「VRChat 英語学習 翻訳ツール PRD」（2026-11-15）

## 目的

VRChat で英語を練習するために、自分の声の訳を、ペット（四角いブロック）の上の文字として周りのプレイヤーにも見せる。
この設計書は、そのうち Unity で作るアバター側の、最初の段階だけを扱う。

第1段階でできるようになること:

- Expression メニューのトグルをオンにすると、ブロックのペット、その上の文字表示、頭上の看板が出る
- OSC で送った文字が、ペットの上に出て、ほかのプレイヤーにも見える
- トグルをオフにすると、全部消える
- どのアバターにも置けるプレハブになっている

## 全体の中での位置づけ

PRD は4つの作業に分かれる。順番は利用者と合意済み。

1. アバター側（Unity）
   1. **ブロック、文字表示、看板、トグル（この設計書）**
   2. 付いてくる動き
   3. 出現演出（自分のアバター専用。配布物には入れない）
2. スマホのスクリプト A（自分の声の翻訳）
3. ツール B（相手の声をスマホに表示）
4. ローカル AI 版

## やらないこと（この段階では）

- 付いてくる動き、歩きのアニメーション、出現演出
- スマホ側のスクリプト、録音、翻訳
- BOOTH 用のパッケージ化と説明書
- 漢字の表示（KAT の文字は 255 種類までのため）

## 避けたいこと

- `reko` のプレハブ、FX、Expression メニュー、Expression パラメータを書き換えること。今回は Modular Avatar に任せ、ビルド時にだけ合成する
- 炎と銃のギミックを壊すこと
- 他人の素材を、利用条件を確かめずに配布物へ入れること

## 現状

- `reko` の同期パラメータは 50 / 256 ビット使用（炎と銃を含む）
- `reko` の FX はすべて Write Defaults オフ。KAT の前提と合っている
- `reko` のメニューは最上段が埋まっている可能性がある。Modular Avatar はあふれた分を自動で次のページに送るので、問題にしない
- Modular Avatar と KAT は未導入
- 炎と銃は、エディタースクリプトで `reko` の FX などに直接書き込む方式。生成スクリプトは `Assets/natsuki_veer02/Editor/<名前>/`、テストはその下の `Tests/`

## 前提（利用者が先に行う）

1. VCC でこのプロジェクトに Modular Avatar を追加する
2. KAT（KillFrenzy Avatar Text）v1.3.2 の unitypackage を Unity にインポートする（`Assets/KillFrenzy/AvatarText/` に入る）

## 作り方の候補と選んだもの

| 案 | 内容 | 良い点 | 悪い点 |
|---|---|---|---|
| **A（採用）** | KAT の部品を Modular Avatar のプレハブに組み込む | `reko` を書き換えない。どのアバターにも置ける。KAT の送信形式がそのまま使える | 漢字が出せない可能性が高い |
| B | KAT のインストーラーで `reko` に直接入れ、文字をブロックへ移す | いちばん早い | `reko` の FX が書き換わる。プレハブにならず、配布時に作り直し |
| C | 文字表示を自作する | 漢字も出せるように作れる | 作業量が大きい。同期も遅い |

利用者が A を選んだ。理由は、PRD の「アイテムとして渡す」にそのまま合い、あとで作り直しにならないため。
tastt modular は、送信アプリが PC 用で日本語対応も未確認のため外した。

## 構成

### プレハブ

`Assets/natsuki_veer02/Translator/TranslatorPet.prefab`。アバターの一番上に置いて使う。

```
TranslatorPet            … MA Parameters / MA Menu Installer / MA Merge Animator
├ Pet_Root               … 初期は非アクティブ
│  ├ Pet_Block           … 四角いブロック
│  └ Pet_Text            … KAT の文字表示（ブロックの頭上）
└ Sign_Root              … MA Bone Proxy で頭の骨に付ける。初期は非アクティブ
   └ Sign_Board          … 看板
```

- **ペットの位置**: この段階では、アバターの右 0.5 m の足元に固定する。アバターと一緒に動く。付いてくる動きは第2段階で `Pet_Root` に足す
- **ブロック**: Unity の立方体、一辺 0.25 m。前が分かるよう、目を描いたテクスチャをスクリプトで作って貼る。シェーダーは Unity 標準のものにし、lilToon を前提にしない
- **文字表示**: KAT の文字オブジェクト（メッシュとマテリアル）を `Pet_Text` に置く。ブロックの上面から 0.15 m 上
- **看板**: 頭の上 0.25 m。文は「Since I can't speak your language, I'm using a translator.」。スクリプトが PNG を作る。文を変えるときは PNG を差し替える。前後どちらからも読めるよう、板を背中合わせに2枚置く。光の影響を受けないシェーダーにする

### パラメータ

| 名前 | 型 | 同期 | 保存 | 役割 |
|---|---|---|---|---|
| `TranslatorActive` | Bool | あり | なし | 機能全体のオン・オフ。VRChat が OSC でスマホにも伝える |
| `TranslatorLocalAI` | Bool | あり | あり | 使う AI の切り替え（オフ: Gemini、オン: スマホのローカル AI）。アバター側では何も動かさない |
| `KAT_Visible` | Bool | あり | なし | 文字表示の出し入れ |
| `KAT_Pointer` | Int | あり | なし | 書き換える場所。255 で全消去 |
| `KAT_CharSync…` | Float | あり | なし | 文字。本数は同期設定で決まる |

- KAT のパラメータ名は、KAT の決まりのまま使う（送信側と合わせるため）。正確な名前は、KAT を入れてから付属のアニメーターで確かめる
- `TranslatorActive` は保存しない。アバターを読み込んだだけで声を聞き始めないようにするため
- KAT の同期設定は 8（74 ビット）を初期値にする。合計は 50 + 2 + 74 = 126 ビットで、256 に収まる。設定は定数で 4 / 8 / 16 に変えられるようにする

### メニュー

MA Menu Installer で、サブメニュー「翻訳」を足す。中身は2つ。

- 「翻訳」トグル（`TranslatorActive`）
- 「ローカルAI」トグル（`TranslatorLocalAI`）

### アニメーター

MA Merge Animator で FX に2つ合成する。どちらも Write Defaults オフ。

1. **オン・オフのレイヤー**（自作）: `TranslatorActive` がオンの間、`Pet_Root` と `Sign_Root` を有効にする。あわせて VRC Avatar Parameter Driver で `KAT_Visible` を同じ値にする。オフにしたときは `KAT_Pointer` を 255 にして、文字を消しておく
2. **KAT のレイヤー**: KAT 付属のアニメーターを使う。同期設定ごとのアニメーターが付属していない場合は、KAT のインストーラーの生成処理を呼び出して、プレハブ用のアニメーターを作る

### 試し送信スクリプト

`Tools/translator/kat_send_test.py`（PC で動かす。Python 標準ライブラリのみ）。

- 引数の文字列を KAT の形式に変換し、`127.0.0.1:9000` へ OSC で送る
- 128 文字を超える分は切り捨てる（分割送信はスマホ側の作業で作る）
- 文字を番号に変換する表は、KAT の文字セットに合わせる。この部分はあとでスマホ側のスクリプトがそのまま使えるよう、単独の関数にする

### 生成スクリプト

- 場所: `Assets/natsuki_veer02/Editor/Translator/`。1ファイル 600 行以内、役割ごとに分ける
- 定数は `TranslatorConfig.cs` にまとめる（大きさ、位置、同期設定、名前、看板の文）
- メニュー項目は2つ: 「プレハブを作る」と「選択中のアバターに置く」。メニューの場所は炎・銃に合わせる
- 何度実行しても同じ結果になる。プレハブと生成物（テクスチャ、マテリアル、アニメーション、アニメーター）は `Assets/natsuki_veer02/Translator/` に作り直す
- 「選択中のアバターに置く」は、シーン上のアバターの一番上にプレハブのインスタンスを置くだけ。すでにあれば何もしない

## 日本語の表示

KAT を入れたら、最初に日本語の文字セットで何が出せるかを確かめる（ひらがな、カタカナ、漢字、記号）。

- かなが出せる場合: 日本語の文字セットを使う。英字と記号も問題なく出ることを確かめる
- 漢字が出ない場合（見込み）: PRD のとおり、英訳の表示を優先する。和訳をどこに出すかは、スマホ側の作業で決める
- 確かめた結果（使える文字と番号の表）は、この設計書の末尾に追記する

## エラー処理

- Modular Avatar または KAT が見つからないときは、何も作らず、入れるものを書いたメッセージを出して止める
- 「選択中のアバターに置く」で、アバターが決まらないときはエラーで止める（決め方は炎・銃と同じ）
- 置いたあとの同期パラメータの合計が 256 ビットを超えるときは、置かずに、合計と対処（同期設定を下げる）を表示する

## KAT 調査結果（2026-11-16、KAT v1.3.2 / Modular Avatar 1.18.7）

### KAT

- 場所: `Assets/KillFrenzy/AvatarText/`。ライセンスは MIT（著作権表示とライセンス文を配布物に入れれば同梱できる）
- スクリプトは asmdef なし（`Assembly-CSharp` に入る）。asmdef を持つ生成スクリプトからは直接参照できないので、リフレクションで呼ぶ
- アニメーターは付属の固定品ではなく、`KillFrenzy.AvatarTextTools.Utility.KatAnimatorInstaller.InstallToAnimator(AnimatorController, KatSettings)` が空のコントローラーに作る。`new KatSettings(KatSDK.VRChat, installKeyboard: false, KatAttachmentPoint.None, syncParamsSize)` で、キーボードなしのレイヤーだけができる
- パラメータ: `KAT_Visible`（Bool）、`KAT_Pointer`（Int）、`KAT_CharSync0`〜`KAT_CharSync{N-1}`（Float）。キーボードを入れないので `KAT_Keyboard`（Bool）は不要
- 同期ビット: `1 + 8 + 8N`。N=8 で 73（公式の 74 はキーボードの Bool 込み）。全体は 50 + 2 + 73 = 125
- ポインタ: 1〜`128/N`。ポインタ p は文字 `(p-1)*N`〜`(p-1)*N + N-1` を書く。0 は待機、255 は全消去
- 文字の番号から Float: 番号 0〜127 は `番号/127`、129〜255 は `(番号-256)/127`。128 は送れない
- アニメーションのパス: `KillFrenzyAvatarText`（`m_IsActive`）と `KillFrenzyAvatarText/Constraint/Text`（`material._Char0`〜`_Char127`）。MA Merge Animator を相対パスで使い、同じ名前の階層をその下に作れば、クリップを書き換えずに済む
- 文字オブジェクト: `Quad`、大きさ `(0.5, 1/6, 1)`、マテリアルは `Resources/KAT_Misc/KAT_Text.mat`（32 文字 × 4 行）

### 文字セット（`Textures/KAT_CharTiles.png`、16 × 16 マス）

日本語は別のテクスチャではなく、同じ1枚に入っている。

| 番号 | 中身 |
|---|---|
| 0〜94 | ASCII。番号 = 文字コード − 32（0 は空白） |
| 95 | € |
| 96〜126、128 | 空き |
| 127 | ぬ |
| 129〜143 | ふあうえおやゆよわをほへたてい |
| 144〜159 | すかんなにらせちとしはきくまのり |
| 160〜175 | れけむつさそひこみもねるめろ。ぶ |
| 176〜191 | ぷぼぽべぺだでずがぜぢどじばぱぎ |
| 192〜207 | ぐげづざぞびぴごぁぃぅぇぉゃゅょ |
| 208〜223 | ヌフアウエオヤユヨワヲホヘタテイ |
| 224〜239 | スカンナニラセチトシハキクマノリ |
| 240〜255 | レケムツサソヒコミモネルメロ゛゜ |

- **ひらがなとカタカナは出せる。漢字は出せない**
- 入っていない文字と、送信側での置き換え: 「っ」→「つ」、「ー」→「-」、「、」→「,」、カタカナの小さい字（ッャュョァィゥェォ）→大きい字、カタカナの濁音・半濁音→元の字＋「゛」「゜」、全角の英数字と記号→半角。それ以外（漢字、絵文字）は「?」
- 空きが 31 マスあるので、あとで「っ」「ー」「、」などを自分で描き足したテクスチャを作ることはできる（今回はやらない）

### Modular Avatar

- アセンブリ `nadena.dev.modular-avatar.core`、名前空間 `nadena.dev.modular_avatar.core`
- `ModularAvatarParameters.parameters`（`ParameterConfig`: `nameOrPrefix`、`syncType`、`saved`、`defaultValue`、`hasExplicitDefaultValue`、`localOnly`）
- `ModularAvatarMenuInstaller.menuToAppend`
- `ModularAvatarMergeAnimator`（`animator`、`layerType`、`pathMode = Relative`、`matchAvatarWriteDefaults`）
- `ModularAvatarBoneProxy`（`boneReference`、`attachmentMode`）

### 実装時の判断

- 階層を `Pet_Root/Pet_Text/KillFrenzyAvatarText/Constraint/Text` にし、KAT 用の Merge Animator は `Pet_Text` に置く（KAT のクリップをそのまま使うため）
- KAT の表示・非表示は KAT 自身のレイヤーが `KAT_Visible` で切り替える。自作のレイヤーは Parameter Driver で `KAT_Visible` を動かす

## レビュー後の変更（2026-11-16）

- トグルをオンにしたときも文字を消す（オフ中に届いた文字が、オンにした瞬間に出ないように）
- 送信側は `KAT_Visible` を送らない（表示の出し入れはトグルに任せる）。各回でポインタを文字より先に送る。消去のあとは2回分待つ
- 看板の Bone Proxy を「回転を保つ」（`AsChildKeepRotation`）に変更。頭の骨が傾いているアバターでも看板がまっすぐになる
- アバターがすでに同じ名前のパラメータを持つとき、ビット数を二重に数えない
- アバターにすでに KAT が入っているときは置かない（2つの KAT が同じパラメータを取り合うため）

### 後回しにしたこと

- 送信を1回で終えるので、あとから入った人には最後の 8 文字しか見えない。スマホ側のスクリプトで、表示中は全体を繰り返し送る
- アクセント記号つきの文字や、肌の色つきの絵文字は「?」が2つになる
- 128 文字目で切るとき、「ガ」のような2マスの文字が半分になることがある
- 作り直すたびに、アニメーターとクリップの GUID が変わる（プレハブも同時に作り直すので、今は問題ない）
- Modular Avatar がないとスクリプトがコンパイルできないため、「Modular Avatar を入れてください」という案内は出ない
- 送信スクリプトは同期設定 1 と 2 も受け付けるが、プレハブは 4・8・16 だけに対応している
- シーンに置いたプレハブを編集（位置の調整など）してからプレハブを作り直すと、その編集が消える可能性がある（未確認）

## 第2段階：付いてくる動き（2026-11-16）

利用者の確認で、ペットがアバターと完全に同じ速さで動くので見にくいと分かった。PRD の P-1、P-2、P-6、I-5 にあたる「少し遅れて付いてくる」動きを足す。

### 作り方

VRLabs Follower と同じ考え方（MIT）を、VRChat Constraints で組む。プレイモードの試作で、遅れて付いてきて最後に追いつくことを確かめた。

```
TranslatorPet
├ Pet_Target   … アバターの右 0.5 m。ペットが待つ位置（アバターと一緒に動く）
├ Pet_Root     … VRC Parent Constraint（Freeze To World）。世界に固定する入れ物。トグルで出し入れ
│  └ Pet_Follow … VRC Parent Constraint。ソース0 = 自分（重み 1）、ソース1 = Pet_Target（重み 0.04）
│     ├ Pet_Block / Pet_Face
│     └ Pet_Text（KAT）
└ Sign_Root
```

- 毎フレーム、前のフレームの位置と Pet_Target の位置を 1 : 0.04 で混ぜる。歩くと少し後ろを付いてきて、止まると右に並ぶ。向きも同じように遅れて合わせる
- 速さはフレームレートで変わる（60 fps で、約 0.4 秒で差が 1/3 になる）。重みは `TranslatorConfig.FollowWeight` で変えられる
- 出現: トグルをオンにした直後の 0.25 秒だけ、ソース1 の重みを 1000 にして、すぐ横に来させる（前に消した場所から飛んでこないように）
- オン・オフのレイヤーは Off → Appear（0.25 秒）→ On。KAT の消去と表示は Appear と Off で行う
- 制約は 2つ、深さ 2。オフの間は Pet_Root ごと無効になる
- 文字表示はペットの子なので、一緒に動く（P-6）

### 決めたこと（変えられる）

- 遅れの強さは 0.04（「少し遅れて」の目安。実機で見て調整する）
- 歩きのぴょんぴょん跳ねる動き（P-4/P-5）と、テレポートしたときの扱いは、この段階ではやらない

## 第3段階：跳ねる動きとテレポート（2026-11-16）

利用者の依頼で、第2段階で後回しにした2つを足す。

### 歩くと跳ねる（P-4、P-5）

- VRChat の組み込みパラメータ `VelocityMagnitude`（移動の速さ、m/s）で判定する。ほかのプレイヤーの画面でも同じ値が使える
- 速さが 0.5 を超えたら跳ね始め、0.3 を下回ったら、その回の着地を待って止まる（始めと終わりの値を分けて、ゆっくり歩いたときにちらつかないようにする）
- 1回 0.4 秒、高さ 12 cm。着地でつぶれ、頂点で縦に伸びる
- 跳ねるのはブロックと目（`Pet_Hop`）だけ。文字表示は跳ねず、読みやすさを保つ
- アニメーターは `Translator_Hop.controller` を `Pet_Follow` に Merge Animator で合成する

### テレポートしたとき

- `Pet_Target` に Contact Receiver（Constant、半径 4 m、`TranslatorPetNear`）、`Pet_Follow` に Contact Sender を置く。タグは `TranslatorPetHome`。自分のアバターの送り手だけに反応する
- ペットが待つ位置から 4 m 以上離れると、トグルのレイヤーが `CatchUp` に移り、Appear と同じ強さですぐ横に来る。戻ったら `On` に戻る。文字は消さない
- 歩いたり走ったりするだけでは 4 m も遅れないので、テレポートやリスポーンのときだけ働く
- `Pet_Target` もトグルで出し入れし、オフの間は Contact も止まる

## 第4段階：ロボットの見た目と、しぐさ（2026-11-16）

利用者の依頼（見本の画像あり）で、ブロックを小さな丸いロボットに変え、しぐさを足した。

- **見た目**: Unity の基本の形だけで作るオリジナルのロボット（高さ 40 cm）。白い丸い体と大きな頭、黒くつやのある顔の画面、水色に光る輪の目、灰色の耳、短い腕と足、胸の小さな画面に点の笑顔。外部のモデルを使わないので、配布してよい。見本の製品そのものの形や文字（型番など）はまねしない
- **その場で向きを変えただけなら動かない**: ペットが待つ位置（`Pet_Heading`）は、位置はいつもアバターに合わせ、向きは歩いている間だけアバターに合わせる（`VelocityMagnitude` で判断。止まっている間は向きを保つ）。テレポートしても位置は付いてくる
- **こちらを見たら、こちらを向く**: 頭から前へ 2 m の見えないカプセル（Contact Sender、`Pet_Gaze`）がロボットに当たると、ロボットが頭のほうへ 0.3 秒かけて向く（Aim Constraint、左右の回転だけ）。目をそらすと戻る。自分の視線にだけ反応する
- **撫でるとハート**: 頭に手か指が触れると（自分でもほかの人でも）、ピンクのハートがふわっと出る。最低 1 秒は出る
- **立っている間、少し前後に動く**: 待つ位置を 8 秒かけて前後に 15 cm ずつ動かし、ペットがそれを遅れて追う
- 制約は 5 つ、Contact は受け手 3・送り手 2、パーティクル 1（最大 20 粒）。同期パラメータは増えない（125 / 256 ビット）
